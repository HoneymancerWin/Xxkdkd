# Avito Monitor → Telegram

Следит за поисками на Авито и сразу присылает в Telegram новые объявления, если они:

- **дешевле рынка** на заданный % (рынок — медиана цен по выдаче и истории за N дней, крайние значения отсекаются), и/или
- **не дороже** заданной цены (`max_price`).

Для каждого подходящего по цене объявления бот открывает его страницу и анализирует:

- **описание**: ищет тревожные признаки («разбит», «трещины», «не включается», «iCloud», «на запчасти», «копия», «предоплата», «пишите в WhatsApp»…) и хорошие («есть чек», «гарантия», «полный комплект», «как новый»…). Учитывает отрицания: «без царапин» и «сколов нет» не считаются дефектом;
- **характеристики и состояние** («Новое», «Б/у», «На запчасти»);
- **продавца**: рейтинг, число отзывов, частник или компания, с какого года на Авито.

**Состояние б/у.** Главный источник — обязательное поле «Состояние» на Авито (Новое / Отличное / Хорошее / Удовлетворительное / Требует ремонта). Описание его уточняет:

| Поле на Авито | Описание | Итог |
|---|---|---|
| Новое | — | **новое** ✅ (купил — не пригодилось, подарили; отключается `allow_new: false`) |
| Отличное / Как новое | пустое или без замечаний | **отличное** ✅ |
| Отличное | «есть царапина», «потёртости» | следы износа ❌ |
| любое | «трещина», «разбит», «не включается»… | дефекты ❌ |
| Хорошее | что угодно | следы износа ❌ |
| Удовлетворительное / Требует ремонта | — | дефекты ❌ |
| только «Б/у» (старые объявления) | «идеальное», «без царапин»… | отличное ✅, иначе ❌ |

Если поле не удалось прочитать (например, Авито поменял вёрстку), объявление не теряется: оно приходит с пометкой.

С `condition_grade: excellent` приходят только «отличные». Для телефонов бот ещё вытаскивает процент АКБ («АКБ 89%», «ёмкость 92%»), и его можно ограничить через `min_battery`.

Из этого складывается **оценка сделки 0–10**. По рейтингу, отзывам, состоянию, типу продавца, стоп-признакам и минимальной оценке можно отсеивать объявления.

Пример уведомления:

```
🔥 iPhone 13 128GB, Москва
iPhone 13, 128 ГБ
💰 15 500 ₽
📊 Рынок ~20 000 ₽ · дешевле на 22%
📦 Состояние: Б/у → отличное (по описанию: идеальное, без царапин)
🔋 АКБ: 91%
🔧 Встроенная память: 128 ГБ · Цвет: синий
👤 Алексей · ⭐ 4.9 · 137 отзывов · Частное лицо · с марта 2019
🧮 Оценка сделки: 9/10
✅ идеальное состояние, без царапин, полный комплект, есть чек
📝 Телефон в идеальном состоянии, без царапин и сколов…
```

Также сообщает, если старое объявление **подешевело** до выгодной цены. Уже виденные объявления повторно не присылаются.

## Запуск на сервере (VPS) — работает 24/7

Подойдёт любой VPS в России на Ubuntu 22.04/24.04, 1 ядро и 1 ГБ памяти. Подключитесь по SSH (с телефона — через Termius) и выполните:

```bash
curl -fsSL https://raw.githubusercontent.com/HoneymancerWin/Xxkdkd/ccr-84ad4696-6q8xkk/server.sh | bash
```

Скрипт установит всё нужное, запустит мастер настройки и поставит бота службой (он сам перезапускается после сбоев и перезагрузки сервера). Управление:

| Команда | Что делает |
|---|---|
| `avito logs` | смотреть, что происходит (выход — Ctrl+C) |
| `avito edit` | поправить `config.yaml` и перезапустить |
| `avito setup` | настроить заново через мастер |
| `avito restart` / `stop` / `start` | управление службой |
| `avito update` | обновить бота |

## Запуск на Android-телефоне (Termux) — в фоне

1. Установите из F-Droid **Termux** (https://f-droid.org/packages/com.termux/) и **Termux:Boot** (https://f-droid.org/packages/com.termux.boot/) — для автозапуска после перезагрузки. Версии из Google Play устарели. Termux:Boot откройте один раз.
2. В Termux выполните:
   ```bash
   pkg install -y git && git clone -b ccr-84ad4696-6q8xkk https://github.com/HoneymancerWin/Xxkdkd.git avito && bash avito/termux.sh
   ```
3. Мастер спросит токен бота, ссылку на поиск и цены; chat id определит сам. Затем бот уйдёт в фон.
4. Настройки Android → Приложения → Termux → Батарея → «Без ограничений» (на Xiaomi/Huawei ещё включите «Автозапуск»).

Termux можно свернуть — бот работает, пока в шторке висит уведомление Termux. Не нажимайте в нём «Exit».

| Команда | Что делает |
|---|---|
| `avito logs` | что делает бот (выход — Ctrl+C, бот продолжит работать) |
| `avito status` | работает ли |
| `avito stop` / `start` / `restart` | управление |
| `avito edit` / `setup` | настройки |
| `avito update` | обновить бота |

## Установка

```bash
pip install -r requirements.txt
cp config.example.yaml config.yaml
```

1. Создайте бота у [@BotFather](https://t.me/BotFather) и вставьте токен в `config.yaml`.
2. Напишите своему боту что-нибудь (иначе он не сможет вам писать).
3. Узнайте свой chat id у [@userinfobot](https://t.me/userinfobot) и укажите его в `chat_ids`.
4. Проверьте связь: `python -m avito_monitor --test-telegram`

## Настройка поисков

Откройте Авито, настройте поиск (город, категория, фильтры), отсортируйте «По дате» и скопируйте URL в `searches`.

| Параметр | Что делает |
|---|---|
| `discount` | на сколько % ниже рынка должна быть цена |
| `max_price` | абсолютный потолок цены |
| `market_price` | рыночная цена вручную; если не задана, бот считает медиану по выдаче за `history_days` дней |
| `min_price` | отсекает мусор и скам («iPhone за 1000 ₽») |
| `include` / `exclude` | слова, которые обязательно должны быть / не должно быть в заголовке |
| `pages` | сколько страниц выдачи читать (больше → точнее рынок, но выше риск блокировки) |
| `min_samples` | пока в истории меньше цен, проверка по рынку не срабатывает |
| `details` | открывать объявление для анализа (по умолчанию `true`) |
| `min_seller_rating` / `min_seller_reviews` | пороги рейтинга и числа отзывов продавца |
| `conditions` | допустимые состояния, например `["Новое"]` |
| `seller_types` | `["Частное лицо"]` или `["Компания"]` |
| `reject_red_flags` | признаки, при которых объявление отсеивается сразу |
| `min_score` | минимальная оценка сделки |
| `condition_grade` | `excellent` — только отличное/идеальное б/у, `good` — без дефектов |
| `allow_new` | по умолчанию новые тоже приходят (купил — не пригодилось, подарили); `false` — отсеивать |
| `allow_unknown_condition` | присылать ли, если состояние не описано |
| `min_battery` / `require_battery` | минимум АКБ в %, и отсеивать ли, если процент не указан |

Списки тревожных и хороших признаков лежат в `avito_monitor/analysis.py` (`RED_FLAGS`, `GREEN_FLAGS`), их легко дополнить под свою категорию.

Если заданы и `discount`, и `max_price`, должны выполняться оба условия. Если не задано ни одно, приходят все новые объявления (простой мониторинг).

## Запуск

```bash
python -m avito_monitor            # бесконечный цикл
python -m avito_monitor --once -v  # один проход с подробным логом
```

При первом запуске бот только запоминает текущую выдачу, а уведомления начинают приходить со следующего прохода.

Для запуска 24/7 на сервере подойдёт systemd, `screen`/`tmux` или cron с `--once`.

## Блокировки

Авито ограничивает частые запросы. Бот маскируется под Chrome (`curl_cffi`), делает паузы и при 403/429 уходит на паузу от 5 до 60 минут. Если блокировки повторяются:

- увеличьте `interval` (300 с и больше) и уменьшите `pages`;
- укажите `proxy` (лучше всего резидентный или мобильный);
- не запускайте с серверов за пределами РФ: их часто режут.
