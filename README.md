# Avito Monitor → Telegram

Бот сам следит за Авито и присылает в Telegram объявления **дешевле рынка** по популярной технике:

📱 iPhone · 📱 Google Pixel · 💻 MacBook · 🎮 Steam Deck (LCD/OLED) · 🎮 Xbox Series S (и X) · 🎮 PlayStation 5 (и 4)

Ничего настраивать вручную не нужно — только токен бота.

## Как он думает

1. **Определяет модель** по названию: «Айфон 12 про 8/128» → *iPhone 12 Pro 128GB*, «Стим дек олед 1тб» → *Steam Deck OLED 1TB*, «MacBook Air 13 M1» → *MacBook Air M1 13"*. Чехлы, игры, геймпады, ремонт, «куплю» — отбрасывает.
2. **Считает рынок отдельно для каждой модели** — медиана цен за 3 недели (битые объявления не учитываются). iPhone 13 128GB сравнивается только с iPhone 13 128GB.
3. Если новое объявление дешевле рынка на 20%+ — **открывает его и проверяет**:
   - состояние (обязательное поле Авито + описание: царапины, трещины, iCloud…);
   - аккумулятор (для телефонов и ноутбуков);
   - продавца: рейтинг, отзывы, частник/компания;
   - признаки мошенничества (предоплата, «пишите в WhatsApp»).
4. Подходит — присылает с оценкой сделки 0–10 и кнопками.

## Кнопки в Telegram

| Кнопка | Что делает |
|---|---|
| 🔥 Находки | последние находки; ✅ купил / 👎 убрать |
| 🛒 Покупки | что купили, сколько сэкономили; «💰 Продал» — записать продажу и посчитать прибыль |
| 📦 Категории | включить/выключить iPhone, MacBook, PS5… |
| 📈 Цены | текущие рыночные цены по моделям |
| ⚙️ Настройки | город, % ниже рынка, состояние, рейтинг/отзывы продавца, АКБ, частота проверок |
| 🔄 Проверить сейчас | внеочередная проверка |
| ⏸ Пауза | остановить/продолжить |

Под каждой находкой: **🔗 Открыть на Авито · ✅ Купил · 👎 Не интересно**.

## Установка на Android (Termux) — работает в фоне

1. Создайте бота: в Telegram **@BotFather** → `/newbot`, скопируйте токен.
2. Установите из F-Droid **Termux** (https://f-droid.org/packages/com.termux/) и **Termux:Boot** (https://f-droid.org/packages/com.termux.boot/), откройте Termux:Boot один раз.
3. В Termux:
   ```bash
   pkg install -y git && git clone -b ccr-84ad4696-6q8xkk https://github.com/HoneymancerWin/Xxkdkd.git avito && bash avito/termux.sh
   ```
4. Вставьте токен, откройте своего бота и нажмите «Старт». Всё — дальше кнопки в Telegram.
5. Android → Приложения → Termux → Батарея → «Без ограничений» (Xiaomi/Huawei: ещё «Автозапуск»).

**VPN для Termux выключите** — с зарубежных IP Авито не пускает (ошибка 439). Лучше всего работает через мобильный интернет.

Оформление: `avito theme mocha` (по умолчанию), `dracula`, `nord`, `tokyo` или `default` — цветовая тема, приветствие со статусом бота, ряд клавиш Ctrl/стрелки. Шрифт меняется через приложение **Termux:Styling** (F-Droid): долгое нажатие на экран → More → Style.

Команды в Termux: `avito logs` (что делает бот, выход Ctrl+C), `avito status`, `avito stop`/`start`/`restart`, `avito update`, `avito setup` (сменить токен).

## Установка на сервер (VPS)

```bash
curl -fsSL https://raw.githubusercontent.com/HoneymancerWin/Xxkdkd/ccr-84ad4696-6q8xkk/server.sh | bash
```
Те же команды `avito …`. Нужен VPS с российским IP.
