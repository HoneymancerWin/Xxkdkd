# Прошивка телефона

> ⚠️ Разблокировка загрузчика **стирает все данные** на телефоне. Сделай резервную копию.
> Телефон должен быть куплен не у оператора (у операторских Pixel загрузчик часто заблокирован навсегда).

## Подготовка телефона (один раз)
1. **Настройки → О телефоне** → 7 раз нажми на «Номер сборки», чтобы включить режим разработчика.
2. **Настройки → Система → Для разработчиков** → включи **«Заводская разблокировка» (OEM unlocking)**.
3. Выключи телефон, зажми **Питание + Громкость вниз**, чтобы войти в режим fastboot.
4. Подключи к компьютеру кабелем и выполни:
   ```bash
   fastboot flashing unlock
   ```
   Подтверди на телефоне кнопками громкости и питания.

## Установка KimderheimOS
```bash
cd $SRC_DIR/releases/<номер>/release-<DEVICE>-<номер>/
unzip <DEVICE>-factory-<номер>.zip
cd <DEVICE>-install-<номер>/
bash flash-all.sh
```

## Первая проверка
Загрузи систему **с разблокированным загрузчиком** и проверь, что всё работает:
загрузочная анимация, обои, форма иконок, шрифт, Wi-Fi, камера, звонки.

## Блокировка загрузчика своим ключом (рекомендуется)
Так система будет защищена Verified Boot так же, как оригинальная GrapheneOS.

> ⚠️ Блокируй **только если система нормально загружается**. Иначе после блокировки
> восстановить телефон будет очень трудно. После блокировки зайди в «Для разработчиков» и
> **выключи** «Заводскую разблокировку» только когда полностью уверен в сборке.

В режиме fastboot:
```bash
fastboot erase avb_custom_key
fastboot flash avb_custom_key $KEYS_DIR/<DEVICE>/avb_pkmd.bin
fastboot flashing lock
```
При загрузке телефон покажет жёлтое предупреждение «Your device is loading a different
operating system». Это нормально для системы со своим ключом.
